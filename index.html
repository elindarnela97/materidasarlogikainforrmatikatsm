Materi Dasar Gerbang Logika

Aplikasi Sistem Digital pada Kelistrikan Sepeda Motor (TSM)

Konsep Penting Logika Biner Otomotif:
• Nilai 1 (HIGH): Sakelar Tertutup / ON / Ada Arus Listrik / Komponen Aktif.
• Nilai 0 (LOW): Sakelar Terbuka / OFF / Arus Terputus / Komponen Mati.

1. AND (Seri) - Kelompok 1

Aturan: Output 1 HANYA JIKA semua input 1.

Analogi TSM: Kunci Kontak AND Tombol Starter.

Input AInput BOutput (Y)
000
010
100
111 (ON)

2. OR (Paralel) - Kelompok 2

Aturan: Output 1 JIKA salah satu/semua input 1.

Analogi TSM: Rem Depan OR Rem Belakang.

Input AInput BOutput (Y)
000
011 (ON)
101 (ON)
111 (ON)

3. NOT (Inverter) - Kelompok 3

Aturan: Membalikkan nilai input (1 input).

Analogi TSM: Standar Samping (Pengaman).

Input A (Standar)Output Y (Pengapian)
0 (Naik / Aman)1 (Mesin Hidup)
1 (Turun / Bahaya)0 (Mesin Mati)

4. XOR (Exclusive OR) - Kelompok 4

Aturan: Output 1 JIKA nilai input BERBEDA.

Analogi TSM: Sakelar Sen Kiri vs Sen Kanan.

Input AInput BOutput (Y)
000
011 (ON)
101 (ON)
110

5. 3-Input AND - Kelompok 5

Aturan: Ketiga sakelar harus bernilai 1.

Analogi TSM: Safety Starter Matik (Kunci + Rem + Starter).

Kunci (A)Rem (B)Tombol (C)Output (Y)
1010
1111 (ON)
